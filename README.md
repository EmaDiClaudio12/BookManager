# BookManager, Assessment 3 (ICT0008 Advanced Programming Skills)

This repository contains the complete implementation of the **BookManager** project, developed for Assessments 2 and 3 of the subject *Advanced Programming Skills (ICT0008)*.

The project includes:

- The **Book** class with all required attributes and methods  
- ISBN-based **sorting function**  
- A test application (**main.cpp**) with correct and incorrect book data  
- Tests for initialization, availability, borrowing, and returning  
- Three arrays of books in **ascending**, **descending**, and **mixed** order  
- Sorting demonstration for all three arrays  
- Console output used as evidence in Assessment 3
